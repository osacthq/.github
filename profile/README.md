# OSACT

**OSACT is the Operating System for Action**: a composable economic system for turning intention into reality.

- [osact.com](https://osact.com/): the home of OSACT
- [osact.ai](https://osact.ai/): OSACT Applied, AI agents, apps and automation built for businesses
- [osact.io](https://osact.io/): OSACT Infrastructure, in private preview
- [osact.app](https://osact.app/): the company workspace
- [osact.org](https://osact.org/): for organizations

Brand files (marks, palette, motion): [osacthq/brand](https://github.com/osacthq/brand).

OSACT is a brand of Not Rest Inc., Costa Mesa, California. It is not affiliated with the OSACT workshop on Open-Source
Arabic Corpora and Processing Tools.
